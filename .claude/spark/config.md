## Gates

always:
- `cargo fmt --all -- --check`
- `cargo clippy --workspace --all-targets -- -D warnings`
- `cargo test --workspace`

when apps/ changed:
- `pnpm -C apps/<app> build` (and `pnpm -C apps/<app> test` when a test script exists)

when apps/console or packages/contract changed:
- `pnpm -C apps/console build` (it ends in check-bundle; a contract that grows raises budgets/bundle.json's `door` line in the same change, measured)

when a change touches live or wall-clock behaviour (the engine, the brain's beat, the daemon's live paths, the stage's live feed):
- a real-engine smoke run on the built binary before ship, read from its artifacts (ledger per-call curve, transcript gaps), not from its exit code. Promoted 2026-10-20: the second spark where only the live run exposed defects (2026-10-18 token growth; 2026-10-20 slow-call silence and a beat-start clock).

when tools/voice changed:
- `python -S -m unittest discover -s tools/voice -t tools/voice` (stdlib only; `-S` proves no site-packages are needed)

when a change touches the brain's beat or the opening (orchestrator, picker, segment states):
- a real sandbox session with the stage held open and the judge on, read beat by beat from `beat_plan` reasons, not only from the gate. Promoted 2026-10-21: the gate passed the first orchestration run while the transcript showed 4 repeated gathering lines; the judge then caught a dropped question and an unannounced poll that unit tests had not modelled.

builder:
- the same three cargo commands, scoped with `-p <crate>` while iterating, then workspace-wide before reporting

## Repo law

- `crates/shadowrunr-types` is the wire contract. Builders never change it: they propose a change in their report and the Director applies it together with `docs/spec/contract.md`.
- Stay inside your package's file scope. When you need a change outside it, report it instead of making it.
- Never `git add -A`, never stash, never commit. The Director stages and commits.
- No credentials in code, config or logs. Accounts are referenced by label and CLAUDE_CONFIG_DIR path only.
- Spawned LLM CLIs run with an explicit tool allowlist, never `--dangerously-skip-permissions`.
- Tests must not spend quota: use `ScriptedEngine` or a fake CLI binary. Live engine calls belong to explicit `--live` runs.
- Optional JSON fields are omitted, never `null`.
- Fabricated cases and data carry `fictional: true` and are never presented as real.
- Malakor and all foils are original characters. No real person's name with a voice or likeness, and no Mattel or He-Man material.
- Windows host: paths through `std::path`, no shell-specific assumptions in Rust; spawn with `CREATE_NO_WINDOW` where relevant.

- Scripts or file content with quotes, backslashes or nested heredocs are written with the Write tool, never a bash heredoc (promoted 2026-10-20 after a second heredoc failure).
- Parallel Rust builders each get their own git worktree forked from the spark branch (own `target/`), so one builder's half-edited crate never breaks another's compile.

- `context-map.json` is generated by a Personas scan, which writes an absolute `project.root`. The repo is public, so set it back to `.` before committing a rescan.

## Skill improvement log

- 2026-10-18: Bash heredocs in this harness collapsed `\\` in a Python regex. Write scripts that contain backslashes with the Write tool, not a heredoc.
- 2026-10-18: Live LLM runtimes hide cost and behaviour defects that unit tests cannot see (warm-session context grew 7.8k to 500k tokens per call; a NOTE leaked into speech). Run a short live pilot right after integration and read its ledger's per-call token curve before any batch run.
- 2026-10-18: Overnight batch runs can be reaped by the harness when other sessions exhaust machine memory. Check free memory and foreign heavy processes first, and keep every batch resumable.
- 2026-10-18: Anchor generated-output ignores to the repo root (`/runs/`, `/data/`); an unanchored `runs/` silently dropped crate test fixtures.
- 2026-10-20 (stream-sandbox): a regression test written from a real-run diagnosis passed against the OLD code on its first try (4.5 s calls never triggered the miscount); only re-tuning to 7 s made it fail old / pass new. Always run the falsification probe before trusting the test.
- 2026-10-20 (stream-sandbox): `git checkout -- <file>` to undo a one-line probe also discarded that file's uncommitted fix; it survived only because a backup copy was taken first. Undo probes from a backup copy, or commit the fix before probing.
- 2026-10-20 (stream-sandbox): a chaos (outage) run must keep its planted stimuli outside the outage window, or the judge measures the outage instead of the host.
