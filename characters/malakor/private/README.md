# private/

Operator material. No loader reads this folder; it never reaches Malakor's prompt. Literal examples that used to sit in the bible and tones, kept for the operator's reference.

- `bible-examples.md`: the quoted samples, the catchphrase and the fixed gag wordings that sat
  in `bible.md` (and the few that sat in `constitution.md` and `directions.md`), verbatim,
  under the section they came from.
- `tone-examples.md`: each tone's old balance line, signature moves and example lines,
  verbatim, under `## <tone>`.

The files the brain reads (`constitution.md`, `bible.md`, `directions.md`, `tones/`,
`effects.toml`) describe effects and behaviour instead. Moving a line from here back into one
of them puts it on air.
