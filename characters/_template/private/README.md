# private/

Operator material. No loader reads this folder; it never reaches the character's prompt. Keep
literal examples here (sample lines, catchphrases, fixed gag wordings) for the operator's
reference, for instance `bible-examples.md` and `tone-examples.md`.

The files the brain reads (`constitution.md`, `bible.md`, `directions.md`, `tones/`,
`effects.toml`) describe effects and behaviour instead. A line moved from here into one of them
is aired as the joke.
